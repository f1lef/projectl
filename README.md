# LNU Map

Студентський застосунок: розклад групи та пошук аудиторій у корпусі ЛНУ.

## Стек і структура

- `mobile/` — React Native, Expo, TypeScript.
- `backend/` — Node.js, TypeScript, Express.
- `docs/` — план першої версії та командна робота.

Початковий проєкт показує демонстраційний розклад ПМК-13. Це не офіційний розклад. Кнопка аудиторії відкриває її номер і поверх; карта ще не реалізована. Бази даних, авторизації й розгортання поки немає.

## Встановлення

Потрібні Git і Node.js LTS, сумісний із Expo SDK 58 (рекомендовано Node.js 24 LTS).

```bash
git clone https://github.com/f1lef/projectl.git
cd projectl
npm --prefix mobile ci
npm --prefix backend ci
```

## Швидкий запуск апки без сервера

```bash
npm run mobile
```

Встановіть Expo Go для версії SDK, зазначеної в `mobile/package.json`, і скануйте QR-код. Телефон і комп’ютер мають бути в одній Wi-Fi мережі. Якщо Expo Go зі магазину ще не підтримує SDK проєкту, оберіть сумісну Android-версію через https://expo.dev/go або використайте development build. Для локального перегляду `.env` не потрібен.

## Запуск із бекендом

У першому терміналі:

```bash
npm run backend
```

Створіть `mobile/.env` за зразком `mobile/.env.example`. Замініть приклад IP на локальну IPv4-адресу комп’ютера:

```dotenv
EXPO_PUBLIC_API_URL=http://192.168.1.10:3000
```

На фізичному телефоні `localhost` означає сам телефон. Дозвольте вхідні з’єднання на порт 3000 у брандмауері лише для своєї приватної мережі.

У другому терміналі:

```bash
npm --prefix mobile start -- --clear
```

Після зміни `.env` перезапустіть Expo. Відкрийте `http://IP-КОМП’ЮТЕРА:3000/api/health` у браузері телефона, щоб перевірити доступність сервера. Якщо адресу API задано, апка завантажує демонстраційний розклад із сервера й показує помилку, якщо сервер недоступний.

## API

| Запит | Результат |
|---|---|
| `GET /api/health` | Стан API |
| `GET /api/groups` | Демонстраційна група ПМК-13 |
| `GET /api/schedule?group=ПМК-13` | Демонстраційні пари групи |

Без `group` повертається 400; для невідомої групи — порожній масив.

## Перевірка й збірка

```bash
npm run typecheck
npm --prefix backend run build
npm --prefix backend start
```

`backend/.env.example` документує порт, але не завантажується автоматично. Щоб задати порт через файл, скопіюйте його в `backend/.env` і запустіть з папки `backend`: `node --env-file=.env dist/index.js` після збірки. За замовчуванням порт 3000.

Не додавайте паролі, токени, `.env` або ключі Firebase Admin у Git. Змінні `EXPO_PUBLIC_*` доступні в застосунку й не призначені для секретів.
